# Git Safety Checklist

## BEFORE Any Git Operation

1. **Check for uncommitted work:**
   ```bash
   git status --short
   ```

2. **Check for stashed work:**
   ```bash
   git stash list
   ```

3. **If you have changes, commit them FIRST:**
   ```bash
   git add -A
   git commit -m "WIP: descriptive message"
   git push origin main
   ```

## NEVER Do These Operations

- ❌ `git filter-branch` (use `git filter-repo` if absolutely needed)
- ❌ `git reset --hard` without checking stashes first
- ❌ `git clean -fd` without backup
- ❌ `git checkout` to overwrite files without committing first
- ❌ `git stash` without immediately applying/popping it

## Safe Daily Workflow

1. **Start of day:**
   ```bash
   git status
   git stash list
   git pull origin main
   ```

2. **During work - commit every 30-60 minutes:**
   ```bash
   git add -A
   git commit -m "Progress: what you did"
   git push origin main
   ```

3. **End of day:**
   ```bash
   git status  # Should be clean
   git push origin main  # Everything should already be pushed
   ```

## Recovery Commands (If Shit Hits Fan)

1. **Find lost work:**
   ```bash
   git stash list
   git log --all --oneline -20
   git reflog --all
   ```

2. **Recover from stash:**
   ```bash
   git stash show stash@{0} --stat
   git stash apply stash@{0}  # Or git checkout stash@{0} -- <files>
   ```

3. **Recover from reflog:**
   ```bash
   git reflog
   git checkout <commit-hash>
   git checkout -b recovery-branch
   ```

## The Golden Rule

**COMMIT AND PUSH EVERYTHING TO MAIN IMMEDIATELY**

No sitting on uncommitted changes. No "I'll commit it later." Push every meaningful change right away.
